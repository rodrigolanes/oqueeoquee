🔒 Política de Privacidade

O que é o que é?

Última atualização: 15 de novembro de 2025

1. Introdução

A Arnapio ("nós", "nosso" ou "nossa") opera o aplicativo móvel "O que é o que é?" (o "Serviço"). Esta página informa sobre nossas políticas em relação à coleta, uso e divulgação de dados pessoais quando você usa nosso Serviço.

Levamos sua privacidade muito a sério. Este aplicativo foi desenvolvido com privacidade em mente, coletando o mínimo de dados necessários para seu funcionamento.

2. Dados que Coletamos

2.1 Dados Coletados Localmente

O aplicativo coleta e armazena APENAS localmente em seu dispositivo:

  • Progresso de visualização: Quais piadas você já viu e quantas vezes
  • Contadores de piadas: Sistema de contagem para garantir variedade
  • Preferências do app: Configurações básicas do aplicativo

Importante: Estes dados são armazenados EXCLUSIVAMENTE no seu dispositivo usando SharedPreferences do Android. Nós NÃO temos acesso a esses dados.

2.2 Dados que NÃO Coletamos

Este aplicativo NÃO coleta, armazena ou transmite:

  • ❌ Informações pessoais identificáveis
  • ❌ Dados de localização
  • ❌ Dados de contatos
  • ❌ Fotos ou arquivos de mídia
  • ❌ Informações do dispositivo
  • ❌ Dados de uso ou análise
  • ❌ Informações de pagamento

3. Como Usamos os Dados

Os dados armazenados localmente são usados exclusivamente para:

  • Salvar seu progresso no aplicativo
  • Garantir que você veja todas as piadas antes de repetir
  • Melhorar sua experiência de uso

4. Compartilhamento de Dados

NÃO compartilhamos, vendemos ou transferimos seus dados para terceiros.

Como não coletamos dados de forma remota, não há nada para compartilhar. Todos os dados permanecem no seu dispositivo.

5. Segurança dos Dados

Os dados são armazenados localmente em seu dispositivo usando mecanismos seguros do Android (SharedPreferences). A segurança desses dados depende da segurança do seu próprio dispositivo.

Recomendamos:

  • Manter seu dispositivo atualizado
  • Usar bloqueio de tela
  • Não fazer root/jailbreak do dispositivo

6. Serviços de Terceiros

Este aplicativo NÃO utiliza serviços de terceiros para análise, propaganda ou qualquer outro propósito que possa coletar dados dos usuários.

7. Privacidade de Crianças

Nosso aplicativo é seguro para todas as idades, incluindo crianças. Como não coletamos nenhum dado pessoal, não há riscos de privacidade para usuários de qualquer idade.

8. Seus Direitos

Você tem o direito de:

  • Acessar seus dados: Todos os dados estão em seu dispositivo
  • Excluir seus dados: Desinstale o app ou use a função de reset no aplicativo
  • Portabilidade: Os dados não são transferíveis entre dispositivos

9. Exclusão de Dados

Para excluir completamente seus dados:

  1. Use o botão "Resetar Contadores" dentro do aplicativo, OU
  2. Desinstale o aplicativo do seu dispositivo

Isso removerá permanentemente todos os dados armazenados localmente.

10. Alterações nesta Política

Podemos atualizar nossa Política de Privacidade periodicamente. Notificaremos você sobre quaisquer alterações publicando a nova Política de Privacidade nesta página e atualizando a data de "Última atualização".

12. Consentimento

Ao usar nosso aplicativo, você concorda com nossa Política de Privacidade e com o processamento de seus dados conforme descrito nesta política.

Esta Política de Privacidade está em conformidade com a Lei Geral de Proteção de Dados (LGPD - Lei nº 13.709/2018) do Brasil.
